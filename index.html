Steps to get your key:

  1. Go to stripe.com and sign up for a free account
  2. Log into the Dashboard at dashboard.stripe.com
  3. Click Developers → API Keys (or go to Dashboard → Settings → API Keys)
  4. You'll see Publishable key — click Copy
